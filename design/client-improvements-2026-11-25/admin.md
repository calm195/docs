# 管理端 · 列表与导航

[打开交互原型](admin.html)。在资料列表输入“高数”，继续选择状态，观察总数与结果一起更新。重置后跳到第 3 页。左侧可切换资料分类或展开“内容治理 › 词库管理 › 发布记录”。资料列表、资料分类和发布记录有独立的示例数据，其余菜单仅展示层级。浏览器打开本地文件即可使用。

## 改动从哪里开始

管理端 develop 基线为 `6036a8efd823020ec1f231c662dcb1df9947b605`。清单来自 `src/router/index.ts` 的实际路由以及 `src/views`、`src/components` 中的表单、列表和嵌套分页。下列组件名均相对于管理端 `src`。以登录角色可见的接口和记录为范围实施。

### 自动搜索的事件和状态

- 文本停输 **300 毫秒**后提交。中文输入法在选词结束后开始计时。枚举、已确定日期、清空和重置立即提交。回车可提前提交相同快照一次。选项变化时合并正在输入的其他有效条件。
- 每次有效条件变化把页码置 1。一次重置多个字段、一次切换分页大小均只发一个列表读取。请求的身份包含页面、会话代次、规范化条件、页码和每页数量。相同请求合并，后发请求取消旧读。即使取消失败，旧响应也不能回填数据、错误、统计或结束新请求的加载态。
- 继续使用各模块的权限检查、请求代次及 `useAdminWorkspace`。列表订阅与详情、写命令分开。输入期间允许继续输入。当前页有未保存操作时沿用现有编辑锁、确认和未知结果重试，避免筛选关闭编辑器或销毁原幂等键。离页、退出、角色改变立即清理读取及页面状态。
- 加载在列表区域内用 `aria-busy` 和“正在查找…”反馈，当前筛选失效时不显示可操作的旧结果。结束后播报条数。自动搜索避免逐键弹出“查询已完成”，显式刷新保留现有操作反馈。未命中可清空筛选。读取失败保留条件，提供“重试”。

## 分页范围与服务端先决条件

| 当前分页来源 | 适配位置 | 数据与实施 |
|---|---|---|
| 完整快照 | 词库管理的词条、版本历史，词库发布记录（`LocalPagination`、`useLocalPagination`）。自动配对的配对、未匹配及排除预览（`MatchmakingAutoPairing`） | 对完整且已授权的快照先筛选、排序，再计数、切片。分组分别计数。 |
| 已有总数与页码或 offset | 活动列表、每日任务库、活动详情的报名/配对（`MatchmakingView`、`MatchmakingTaskLibraryView`）。特质标签（`MatchmakingTraitsView`）。内置词条（`BuiltinWordlistEntries`） | 传目标页，或换算 `offset=(page−1)×size`。活动详情目前共享页码，分页页数按两个列表各自页数的最大值。分别标注报名与配对总数。特质词云是同条件排行前 100 项，列表总数来自列表接口。 |
| 游标上一页/下一页 | 平台用户、资料列表/分类、后台账号、身份审核/历史、内容审核、危机工作台、举报/处罚/申诉、心愿管理/悄悄话管理 | 当前各服务依赖 `next_cursor` 与历史页。为管理端增设有版本的页码查询，下方给出契约。 |
| 游标追加 | 树洞审核、树洞举报、树洞危机（`WhisperReviewsView`、`WhisperReportsView`、`WhisperCrisesView`） | 将“加载更多”迁为只显示目标页，使用同一总数和页跳契约。新页清除不属于该页的行选择，保留单独打开的受保护编辑。 |
| 详情内评论 | 心愿/悄悄话的 `PublicationDetail` | 现有详情取零基 `comments_page`、固定 30 条，并返回 `comments_more`。协议应返回该详情下符合公开展示资格的评论/回复行总数，并明确页数和可用大小，再将界面的一基页码换算到旧参数或新适配器。 |

**统一组件。** 扩展现有 `LocalPagination` 的显示层为共用页脚，沿用 `PageSizeSelect`。页面负责取得数据，组件接收 `page / pageSize / total / allowedSizes / busy`，发出换页、换大小事件。数量按各接口支持范围显示，旧接口固定大小时显示“每页 20 条”等实际值。右侧带“上一页 / 下一页、跳至［ ］页、跳转”，窄屏换两行。显示“共 47 条 · 第 2 / 5 页”。空结果显示“共 0 条 · 0 页”，禁用翻页和跳转。首末页各禁用对应方向。空、零、负数、小数、超界页只提示合法范围，回车与点击共用一次提交。同一筛选下记录变少导致请求页消失时，服务端给出最新范围，客户端只回取新的末页一次。

**拟议接口。** 旧接口继续服务现有客户端。为游标资源增加明确区分的管理端页码读取模式，例如同一资源 `pagination=numbered&page=3&page_size=10`。原严格响应解析器与旧请求保持兼容。新模式返回 `{items, page, page_size, total}`，服务端可由 total 推导末页，前端计算 `ceil(total/page_size)`。初次集成先验证资料列表。总数与行使用相同授权、过滤、顺序（原排序再用唯一键打破并列）和一致性读。每次翻页重新鉴权。实时队列可以变化，同一响应内的页、条数与权限必须一致。只在服务端放行新模式的模块启用跳页，不估算总数或逐页爬取游标。旧界面仅用于迁移，全部目标列表具备准确页数与跳转才可验收。

**两个影响计数的现状。** `useSafety.ts` 的处罚页在已取回的举报页里选 `resolved`。应把“已确认举报”放进数据库筛选，先计数和分页。保留处罚页的数据含义，不把它改成所有处罚历史。`internal/modules/moderation/admin_content.go` 的内容查询每次最多扫描 200 个候选，逐条按当前公开资格匹配标题或正文。可能返回空页和后继游标。为编号模式建立可按相同发布版本、状态、撤回/可见性和关键词查询的集合。计数和目标页均基于该集合，详情统计/投影只读取本页。评论总数同样按实际可展示行校验。实现在本地造边界数据，检查非授权样本不计入总数、深页延迟和数据库查询计划，再逐模块启用。

## 独立导航与文案

- 调整 `AdminLayout.vue`、`assets/styles/layout.css`。桌面外壳使用视口高度，品牌与顶栏保持可见，左侧导航和右侧内容各自可滚动（`min-height:0; overflow-y:auto; overscroll-behavior:contain`）。进入详情、切换页码不移动左栏。手机沿用 760px 断点，菜单为独立滚动抽屉，关闭后恢复触发按钮焦点。
- 父分组使用较重字重、图标及展开箭头。子路由缩进、常规字重，当前目的地用浅紫底、左侧标记和 `aria-current=page`。词库三级再缩进一层。刷新或深链自动展开当前页祖先。分组保留 `aria-expanded/controls`、键盘操作、既有角色过滤及词库子路由。
- 删除左栏和品牌重复的“鲤源池 · WEB 管理端”（`AdminLayout`）、活动列表的“按当前页展示，进入详情管理活动。”（`MatchmakingView`）。移除自动生效后过时的“条件已修改，请重新查询后翻页。”（用户、资料、资料分类），替换重复动作“查询 / 从首页刷新”为按需“刷新”及“重置”。
- `UsersView` 的“认证、限制与注册时间使用当前授权投影”可删，列表表头已经解释字段。`AccountsView` 的“初始口令由服务端仓库外策略提供，此页面不设置或显示口令。”可改为“初始口令通过既有渠道另行提供。” `WhisperCrisesView` 在页头和正文两次描述岗位范围，合并为一次。保留删除不可撤回、结果未知、限制期限、危机人工值班时间及词库试跑说明。上线前按真实角色遍历页面、空态、抽屉和弹窗，核对重复提示与删改后的操作依据。

## 验收用例

1. 在第 3 页输入中文并选词，再切换状态。只使用最终条件，结果回到第 1 页。模拟旧请求晚于新请求返回，列表、统计、报错都属于最后一次输入。连续清除筛选、切换账号、离页重进不带入旧条件。
2. 完整 ID/回执的粘贴只发一次读取。缺字、清空、日期/热度倒置均不发请求。替换或清空敏感标识立即清除上个对象的数据，包括错误与内存中的详情。任何搜索不会触发写入。
3. 对每类分页验证 0、1、整页、多 1 条、末页、无效页、直接跳至未访问页和更改每页数量。以服务端同条件 COUNT 校验总数。举报前一页全是未确认而后一页有已确认时，处罚页首页仍能列出符合条件的记录。跨越 200 个候选后仍能找到公开命中项。
4. 编辑中、已有勾选、批量操作中、失败重试、无权/会话过期分别回归。分页不可重新提交写命令。权限收回须清空行及总数。词条跨页选择在切换筛选时清空，已暂存改动仍受原有提醒保护。
5. 桌面 1280×720 同时展开多个父组，分别滚动两侧与键盘跳转。小屏 390px、200% 缩放、深链词库三级、不同角色与暗色下核对可见范围和当前项。按不同角色比对清理前后界面，保留必要的危险操作与重试提示。

原型只在浏览器使用合成数据演示设计。接口验证、数据库计数与性能、在应用内的路由和权限回归安排在实施阶段。
