## 2. 实现范围与取舍

新增三个只读入口：`GET /api/v1/admin/users`、`GET /api/v1/admin/users/{id}`、`GET /api/v1/admin/users/{id}/penalties`，随现有安全治理服务显式装配，健康模式不装配。HTTP层严格拒绝未知、重复、空非法参数及损坏编码，返回标准错误、`Cache-Control: no-store` 与一致请求ID。

普通资料来自 accounts 白名单；只读 DTO 不序列化 ORM 实体。列表仅取 active，昵称按指定 Unicode White_Space 去边界空白、最多50码点、仅 ASCII A–Z 折叠，SQL使用参数绑定的 translate/strpos 实现字面子串匹配。筛选 AND 组合，在键集截断前完成；限制由有效 penalties 实时聚合，ban优先、warning不限制、禁言取最晚有效结束时间，同次请求共用数据库快照和 as_of。没有引入搜索服务、用户资料副本或全量缓存。

两类列表均取 limit+1，排序分别为 created_at/id、starts_at/id 倒序。游标用既有安全密钥派生独立 AES-GCM 密钥，带随机 nonce；密钥化摘要绑定主体、用途、目标、完整规范化筛选、页大小和排序，密文保护末项键与30分钟绝对到期时间。无需新增默认密钥；不接受样例 synthetic 游标。

处罚历史与有效摘要先按角色过滤危机来源；全局 restriction 独立计算，故可有全局封禁但无可见处罚ID。案件和申诉引用仅对可访问普通来源返回；匿名/危机来源不返回链接。理由使用固定安全文案，不解密自由理由。导航仅在目标实际存在合格普通案件/待办申诉时启用，用户详情提供同一快照的 Account.version，原处罚、申诉及树洞命令 Wire 和版本规则不变。

详情与历史按后台主体、目标账号顺序使用原账号 guard，防止查询审计越过注销清理；注销提交后新读取404，列表及旧游标不回显目标。列表留迹关联后台操作者，不存整页学生ID或筛选值；结构化日志只记筛选类型、数量、操作者、请求ID和耗时。详情/历史留迹关联目标账号，复用原隐私清理链，无新增永久搜索日志表。GORM 使用既有安全服务静默查询日志，HTTP访问日志只记录路由模板。

## 3. 数据库升级与接入

新增迁移 **0027_admin_user_queries**：只增加 `public.is_live_student_session(bytea)` 布尔校验函数，无新表/字段，不修改已应用迁移。函数为固定 search_path 的 SECURITY DEFINER，所有者 liyuanci_migrator，仅授权 liyuanci_admin_api 执行，PUBLIC/学生等运行身份不得执行。

原因：后台 sessions RLS 隐藏学生会话，直接复用查询只能返回401；契约要求有效学生令牌跨域为403。窄函数仅辨别已持有高熵令牌摘要是否为有效学生会话，不返回身份/会话资料，后台仍不能 SELECT 学生会话行。未知、失效令牌401，空角色403；角色与 auth_epoch 每次重验。

接入前用既有**专用迁移身份**显式执行业务迁移及权限刷新，再重启对应API。本地可沿用所选模式显式初始化流程，保留历史凭据、密钥和卷；本轮未升级用户常驻开发库。API/worker普通启动不执行DDL。回退需先停止消费新接口的API，再由迁移入口回退0027；既有迁移工具的 down 会回退全部已应用版本，不能把它直接作为线上单版本回退命令。
