PostgreSQL 是业务权威，Redis 提供共享限流和公开候选缓存。普通 API/worker 不执行 DDL。配置统一读取公共 YAML 与私有环境覆盖；单主密钥、用途派生标签、删除意图账本和已应用迁移保持原有协议。生产现已应用至 `0033`，目录与账本严格连续；本轮新增0032与0033。生产阅读位置迁移已于2026-11-15应用。
