# 管理端后续计划

更新：2026-11-13。现状和版本见[README](README.md)，问题编号见[缺口](defects.md)。

| 顺序 | 工作 | 依赖与关闭标准 |
| --- | --- | --- |
| 1/P1 | 固定配套版本及岗位 | 后端API/worker与0030结构兼容，运营提供超管/审核/危机测试身份；登录恢复、改密、退出及岗位菜单与服务端权限一致 |
| 2/P1 | 全站业务验收（AD-01） | 小程序提供关联测试内容；覆盖身份、心愿图文/评论、词库试跑发布、树洞四工作台、用户、安全申诉、资料分类、字典及包分配全流程 |
| 3/P1 | 权限与失败恢复（AD-02） | 隔离账号及可控撤权/并发版本；核对同键重试、401/403、409、404、换号/离页/迟到与敏感图片清理 |
| 4/P1 | 危机与隐私闭环（AD-03） | 运营值守与隔离恢复环境；关怀、人工接手、证据清理和回执范围有真实结果 |
| 5/P2 | 交互及发布（AD-04） | 当前版本真实API；双主题、窄屏、键盘、弱网、图片和自动分配弹窗通过，随后按发布授权更新站点 |

每批变更执行格式、完整check与build；界面及传输变化补相关行为/浏览器回归。生产部署需记录源码和制品，验证同源代理、history fallback、HTTPS与敏感接口禁止缓存。具体人员与日期按实际资源确定。
