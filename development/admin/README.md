## 架构与会话

Vue 3 Composition API、严格 TypeScript、Pinia 和路由懒加载。页面组织业务交互，组合函数管理工作区生命周期，服务层接收 unknown 并按契约校验。后台访问令牌仅存内存，启动通过同源 HttpOnly Cookie 恢复，岗位仍由服务端复核。

本轮新增 `services/session-transport.ts`，统一七处传输实现的请求前后授权、取消、后台路径、Bearer、禁止缓存/Cookie/重定向边界。读取正文后继续复核授权；各模块的状态码、请求ID、响应头及严格JSON规则保留。内容公共请求独立到 `content-request.ts`，内容查询不再依赖审核与词库客户端实现。

## 页面与能力

| 模块 | 当前能力 |
| --- | --- |
| 会话、账号与首页 | 登录恢复、本人改密、账号岗位管理、退出撤销；首页聚合、区间趋势和热点列表 |
| 身份与内容审核 | 学生卡授权查看、审核原因及修改建议；待审/全部、内容类型与编号筛选；图片展示图和按需原图 |
| 内容与词库 | 心愿/还愿/帖子等查询、统计、评论引用、图片；自定义及内置词库草稿/试跑/发布/恢复、运营分类、缩写、匹配方式和处置级别 |
| 用户与安全 | 用户查询、限制/处置、举报、处罚、申诉、危机案件及证据清理 |
| 悄悄鲤 | 审核、举报、危机、证据四类工作台，匿名资料与岗位访问隔离 |
| 资料与运营 | 资料和分类、COS/外链、反馈；模块说明、展示字典和举报类型维护 |
| 包分配 | 活动、报名、题库、人工配对、自动分配预览/重算/确认、任务及发布；词条治理和双向半分展示 |
