# 管理端现状

更新：2026-10-30。源码核对基点 `2086457c6324fda5d2a6e114c4e90ab4b8325ab8`；本轮只整理文档。入口：[缺陷与缺口](defects.md) · [后续计划](plan.md) · [模块与契约](../../modules.md)。

## 页面与模块

| 模块/入口 | 当前能力 | 重要边界 |
| --- | --- | --- |
| 登录、工作台、改密、账号 | 后台本地账号、角色菜单、本人改密/退出、超管账号维护 | 令牌仅在内存；菜单不能替代服务端授权 |
| 平台用户 `/users` | 昵称搜索、分页筛选、详情、处罚历史；超管直接封禁/解封、禁言7天/取消禁言 | 理由必填，版本及幂等受控；封禁与禁言独立解除 |
| 身份、内容、词库 | 查询与处理分离、授权读卡、批准/拒绝、词库草稿/完整快照/发布及归档 | 按当前案件、正文和词库版本处理；危机正文不向普通审核岗开放 |
| 普通安全治理 | 举报、处罚、申诉独立列表和抽屉 | 沿服务端动作处理；不存在任意用户的通用解罚入口 |
| 树洞审核/举报/危机/证据 | 帖子、暖评、昵称、胶囊审核；危机跟进/误报、证据范围删除与进度查询 | 私密数据只驻留当前页面内存，换号/撤权/离页清理；受理不等于物理清理完成 |
| 资料 `/resources`、`/resource-categories` | 资料创建/编辑/发布/下架、分类管理、四类反馈汇总 | 运营/超管权限；先下架再编辑；分类占用、版本冲突和隐私重放404按契约处理 |
| 布局与交互 | 统一侧栏、面包屑、Element Plus中文组件、浅色/深色/跟随系统 | 查询与处理职责分开；敏感API不可缓存 |

当前入口以[路由](../../../liyuanci-admin-vue/src/router/index.ts)、[服务层](../../../liyuanci-admin-vue/src/services)和[用户直接处置组件](../../../liyuanci-admin-vue/src/components/UserRestrictionActions.vue)核对。启动及同源API代理见[源码 README](../../../liyuanci-admin-vue/README.md)。

## 已有验证与限制

- 2026-10-30同一业务源码版本的 `pnpm check` 通过：758项应用测试、58项规则测试；`pnpm build`通过。
- 用户直接处置有本地浏览器/数据库四操作及角色、审计证据；资料管理有合成浏览器和本地真实HTTP/浏览器验证。
- 2026-10-29新版审核分流与角色边界主要由HTTP/DB检查完成，未覆盖新版管理端全站浏览器复测。历史浏览器通过不能自动覆盖后来全部后端变化。
- 真实关怀/外部通知、完整隐私清理、即时撤权与私密案件逐项验收仍需补齐，见[缺陷与缺口](defects.md)。
