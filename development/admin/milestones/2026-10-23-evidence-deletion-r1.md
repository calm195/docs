## 依赖、取舍与未完成范围

【事实】当前本地配置未提供 EvidenceDeletionDSN。后台删除待办、匿名删除回执均返回 404 且没有对应处理器的 no-store 头，表明本次服务尚未启用隐私删除路由；这些结果不计为已启用服务的业务不存在验证。删除 DELETE 未执行，不能声称真实 202 或 physical completed 已验证。危机后端启动不等于隐私删除后端启用。

【依赖】后端宿主需按既有后端方案提供独立删除 API 连接、独立恢复日志 writer/reader 及恢复包装密钥；物理清理另需独立 purger 和真实外部 Eraser 等依赖。前端不创建数据库账号、不填造配置、不注入模拟清理能力；缺外部清理时 processing 应保留。匿名回执有效期结束并不取消清理。

【范围限制】当前证据读取入口只提供危机证据条目的范围版本；页面从此入口核对版本后才允许删除。后端 DELETE 还接受证据范围 ID，但未提供其他类型范围的对应可读版本入口，本端不编造范围版本或使用危机案件版本替代。后台没有删除待办列表、撤回或手动强制完成接口，本端仅查询已知 ID，不虚设功能。

【未验证】没有指定可删除的合成案件，未操作实际证据、未执行账号注销、未验证 purger/外部对象清理、备份重删或真实匿名回执 processing→completed。本轮为管理端交付，不涵盖小程序本人注销、已注销提示、存活方六行矩阵或三端联调；由后续联合验证使用可处置夹具完成。共享台账留给 docs 协调者维护。

【后续验证条件】启用隐私依赖并提供可删除夹具后，验证真实证据范围版本→DELETE 202→读取阻断→待办 processing/completed，以及未授权拒绝、重复幂等和回执过期。该建议不改变批准需求，也不把缺失依赖当作本次联调通过。
