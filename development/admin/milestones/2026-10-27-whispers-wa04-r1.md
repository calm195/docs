## 实现与可测试验收

| 范围 | 实现与本端可观察结果 |
| --- | --- |
| 角色与独立入口 | 新增懒加载 /whispers/crises（树洞危机），仅危机岗位及超管可访问；/whispers/evidence（树洞证据）仅超管可访问。菜单与路由均检查角色；直挂页面仍检查会话与权限，服务端是最终授权边界 |
| 危机列表 | 仅显示元数据，不预取正文；仅使用契约limit/cursor，空页仍可继续、按ID去重、循环游标停止并提示刷新，失败可重试。分页发现选中案件版本、正文版本、来源或状态变化即清旧详情 |
| 限定详情 | 选案才读CrisisDetail，展示限定正文、来源、案件/正文版本、交接时间、时间线及关怀/工作人员投递状态；文字插值防止HTML执行。not_verified或无学号显示“尚无认证学号”，未认证即使出现非空学号也不展示；无学生卡或身份反查。私密胶囊单独提示限定用途 |
| 危机动作 | CrisisDetail.allowed_actions分别控制通用处理与误报；通用操作支持take_over、follow_up、resolve、retry_notification，使用已读案件version和必填理由（≤500 Unicode码点，保留原空白），二次核对后发送。动作有效性仍由服务端当前状态决定，不虚构细粒度动作授权 |
| 结案、误报与通知边界 | 结案不解除隔离；误报只转普通复核，不直接公开，不重建注销、取消或换版内容；胶囊仍须满足预约到期等条件。通知重试仅作用于仍有效待办，不恢复已取消通知。展示服务端实际回执状态，成功后只保留元数据，清除回执中的正文、学号和时间线，需重新读取详情 |
| 证据元信息 | 危机详情仅超管显示evidence_scope_id与树洞证据入口，入口不携带正文或身份参数；按已知范围UUID读取EvidenceScope，仅读ID/version/state/allowed_actions，无列表、原始证据或手填版本；范围ID变化立即清旧目标 |
| 证据删除 | retained且allowed_actions允许才显示删除入口；超管必须手工输入精确DELETE_EVIDENCE_SCOPE及非空≤500码点理由，核对整个限定范围后发送EvidenceScope.version。deleting或动作为空不开放；受理成功清目标、确认短语与理由，只保留任务ID |
| 删除进度 | 按已知或受理返回的job_id独立手动查询，processing显示尚未全部完成，completed才显示后端确认完成。即使受理响应含completed，也不直接显示清理完成；查询进度不触发删除，无自动轮询。切换任务ID或查询失败清旧进度 |
| 失效与并发 | 404/409清旧目标/正文和表单，要求手工重新读取后核对，不自动重提。换案、离页、换号、撤权或401/403清敏感内存并取消在途请求，晚到正文/任务/处理回执不可恢复；危机开始处理时取消在途分页，防止其重置当前表单 |
| 写入重试 | 每个明确提交生成UUID幂等键，重复点击只发一次；结果未知锁住原键原体、表单编辑、取消及其他查询，仅支持原请求重试。400/429/503明确未执行可修正理由或稍后重试；冲突后不能沿用旧版本 |
