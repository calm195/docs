## 实现与可测试验收

| 范围 | 实现与本端可观察结果 |
| --- | --- |
| 路由及列表 | 新增懒加载 /whispers/reports，安全治理菜单“树洞举报”；安全岗位或超管可访问。列表仅展示元数据，不预取正文；仅使用limit/cursor，空页可继续、按ID去重、循环游标停止并提示刷新，失败可重试 |
| 只读详情 | 选中举报后按其source.kind/id读取ContentControl；正文以文本插值展示，可空举报描述正常呈现。案件、正文及治理版本只读；无作者ID输入、手填版本、全量私密内容入口 |
| 举报判定 | pending且allowed_actions允许时开放confirmed/dismissed；二次核对并发送举报version和必填理由，保留空白，按Unicode码点限制≤500；成功清理正文和表单，后续治理需明确重新读取 |
| 普通限制 | source类型、ID及content_version与ContentControl一致且动作允许才开放；使用ContentControl.version和明确目标restricted布尔值；回执以服务端实际值显示。解除普通限制不等于公开，也不解除危机或隐私门禁 |
| 处罚 | 仅confirmed且治理版本匹配、动作允许时开放；minor对应warning、general对应7天mute、severe对应永久ban。发送ContentControl.version、report_id和举报version，不手填作者ID；回执展示服务端实际处罚类型及ends_at |
| 危机升级 | 需危机岗位或超管并命中举报allowed_actions，使用举报version及必填理由；成功清除正文并显示新危机ID，不跳转旧危机接口。普通治理不因升级入口而获得危机权限 |
| 既有申诉兼容 | 单独扩展申诉投影四种whisper来源及中文标签，旧举报来源范围保持严格；列表、详情及决定响应均支持并绑定案件ID。忽略额外私密字段，不把胶囊正文或作者字段写入申诉投影 |
| 依赖失败与失效 | ContentControl临时失败时仍可读举报和判定，限制/处罚单独禁用；404/409清理旧正文与表单，要求手工重读后决定。换案、失效、离页、换号、撤权取消在途读取，晚到响应不能回填；开始处理时取消分页避免其重置表单 |
| 原请求重试 | 重复点击只发一次；未知写入结果保留原幂等键和请求体，锁定编辑/取消并仅支持原请求重试。明确未执行的400/429/503解除锁定供修正或稍后重试；不自动以新版本重新提交 |
