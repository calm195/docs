## 2. 启动与登录

```sh
cd /Users/kurous/code/liyuanci/liyuanci-admin-vue
pnpm install --frozen-lockfile
pnpm dev --host 127.0.0.1 --port 5173 --strictPort
```

访问 `http://127.0.0.1:5173`，当前Vite将同源 `/api/v1` 转发到 `http://localhost:18080`。若后端不在18080，先由环境维护者交接一致的入口；浏览器端无需自行拼接跨域地址或填令牌。启动要求Node及pnpm版本见[源码README](../../../../liyuanci-admin-vue/README.md)。

1. 使用实际后台账号登录，确认认证请求到达选定后端，随后角色菜单与服务端权限一致。
2. 刷新页面后按当前内存会话策略重新登录，退出后原会话不得继续使用。
3. 由超管按需要创建／授权测试账号；改密成功后重新登录，记录旧会话失效，不保存口令。
4. 与小程序A对应同一测试申请，完成学生认证审核并让A刷新确认，先证明跨端闭环。

## 3. 页面逐项操作与通过标准

本表是管理端页面子项，不替代总册WI全项。所有状态为待执行；补测时记录真实账号、响应、页面和worker结果，禁止开启接口拦截制造成功。

| 登录／权限／WI-16 | 三岗分别登录；超管撤销测试角色，再尝试旧页操作 | 会话域正确；角色撤销后服务端拒绝，页面清理失权详情；菜单隐藏不是唯一证据 |

| 树洞审核／WI-01、08、09 | `/whispers/reviews` 查四类内容命中案件；批准／驳回；制造双版本冲突 | 按案件和正文版本提交；驳回理由及建议完整；冲突后重读；批准、公开、昵称启用、胶囊到期分别显示 |

## 4. 证据、失败与收尾

每项按总册证据格式保存脱敏截图、方法／模板路径、HTTP状态、request_id、版本及预期／实际。禁止保存原始HAR、token、密码、学号和私密正文。证据写 `development/admin/validation/`，新结果写本端新阶段记录，旧WA-05证据不追加改写。

401重新登录并核对域；403查实时角色；409重读当前版本；503定位后端依赖。不得用fixture响应、关闭严格解析或手工改数据库伪装页面通过。`pnpm test:browser`当前拦截业务接口为合成响应，可作界面回归，不能计本册真实联调。

退出测试会话、停止本次Vite进程；账号保留／禁用由环境负责人按本轮计划处理，不删除无关账号。WA-05关闭须同时满足页面清单、对应WI、真实资源与角色／版本边界证据。
