## 实现范围与取舍

【已实现】保留 Vue 3 Composition API、严格 TypeScript、Vue Router、Pinia 与 Vite，新增显式导入的 Element Plus `2.14.7` 组件及简体中文配置；未引入管理模板框架或自动导入插件。入口 JS 构建约 174.47 kB / gzip 66.41 kB，业务页面继续懒加载。

导航使用左侧分组菜单、顶部工具栏及面包屑，保留原角色矩阵；登录页仅显示登录与主题控件。菜单配置的标题与分组映射为路由元数据，面包屑、浏览器标题读取同一来源。工作台上级链接可返回首页，无落地页的业务分组展示文字。提供跳到内容链接、当前菜单标识及窄屏菜单按钮；切换页面时收起移动菜单。

主题包括浅色、深色、跟随系统。只把 `liyuanci-theme` 偏好写入本地存储；系统变化、跨标签更新、存储拒绝、异常值及无 matchMedia 时均有处理。首屏脚本在应用和样式加载前设置主题；原生输入、提示、选中项及身份审核等页面固定色改为语义变量，配合 Element Plus 深色变量。

【兼容性修复】Element Plus `2.14.7` 及试验的 `2.11.5` 均触发 Vue `3.5.44` 中 PropOptions.validator 与 exactOptionalPropertyTypes 的声明兼容问题。最终保留最新选用版本，并通过 pnpm 原生补丁对 Vue 声明作单行修正：校验器可为显式 undefined，与现有运行时行为一致；保留校验器函数参数与返回类型，不修改运行时代码、不放宽项目 TypeScript/ESLint 选项。补丁与锁文件纳入第一模块提交，中英文 README 说明升级时需重新核对。

【尚未实现】本组只完成基础框架。账号抽屉、词库列表/详情/草稿拆页，举报/处罚/申诉独立入口、审核与危机案件详情路由、证据删除和回执分离尚待后续模块实施。现有页面仍保留原业务结构与操作语义，不将导航重构等同于业务拆分完成。
