## 工程落点和边界

- 类型放 src/types/whispers/，外部 I/O 与解析放 src/services/whispers/，行为测试相邻；复用后台会话及传输安全策略，不宽松扩展旧类型，不新增依赖。
- 后续新增懒加载页面 /whispers/reviews、/whispers/reports、/whispers/crises；证据删除复用现有布局并接本包服务。菜单动作只是交互限制，服务端权限为最终依据。
- 仅支持契约 limit/cursor，不发明状态/搜索参数；空页可继续，循环游标停止并提示刷新。敏感正文、令牌和重试请求只放内存。
- 结果未知由调用方保留原键原体重试；版本冲突先重新读取，再由用户决定。离页、撤权、退出和对象失效清正文，晚到响应不可回填。
- 无语音、陌生人私聊、全量胶囊浏览、匿名作者反查、学生卡联查、学校字典或援助目录编辑后台；这些不因本计划新增。

## 验证、依赖和启用

本端使用契约合成样例替代传输，不在产品运行时加入演示成功路径。每组修改执行 pnpm format、pnpm check、pnpm build；docs执行 python3 scripts/check_documents.py 和 git diff --check，包含固定指纹检查。契约消费测试核对18个操作、请求和响应、坏版本/额外字段/未知动作/空值/码点边界、七种结果、同键重试、取消/撤权和资源绑定。

真实联调前后端交接精确SHA、包指纹、已实现接口、角色测试账号、隔离环境、迁移和worker状态；正文、token、真实学号不进证据。重点覆盖 WI-08、WI-09、WI-12、WI-15、WI-16、WI-17、WI-18，兼顾其他用例中的管理端审核观察。学校字典、援助资源、扫描服务与隐私清理依赖按范围阻塞真实验收，不冒充首期完成。

不得先开放文字再补危机和注销；全站启用还依赖后端及小程序完成 opaque 黑名单升级，管理端不替代其实现。完成阶段新增 milestones 记录、validation 证据并追加固定清单。用户2026-10-27后续授权每次完成按模块及依赖顺序提交源码并同步docs；推送、合并、部署与上线仍需各自授权。
