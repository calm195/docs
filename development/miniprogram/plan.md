# 小程序后续计划

更新：2026-11-13。源码与最近上传记录见[现状](README.md)，问题编号见[缺口](defects.md)。

| 顺序 | 工作 | 依赖与关闭标准 |
| --- | --- | --- |
| 1/P1 | 跟进编译链安全更新（MP-09） | 按官方配套组合升级剩余受影响依赖，重新审计并完成单元/构建/真机回归；保留当前本机开发限制 |
| 2/P1 | 对齐版本和正式素材 | API/worker/0030结构配套；运营补MP-01二维码并核对MP-04资料，开发者确认设备与微信权限 |
| 3/P1 | 当前版本双账号闭环（MP-05） | 覆盖心愿图文/评论/收藏/通知、应愿聊天还愿、树洞胶囊、资料、安全隐私及包分配；成功与越权/旧版本负例均有结果 |
| 4/P1 | 真机与原反馈复测（MP-06） | 最新配套包、iOS/Android和原报错设备；验证选图保留、列表/详情图片、导航、换号及迟到响应、弱网/前后台、双主题和键盘 |
| 5/P1 | 并发与隐私（MP-07） | 后端可控时间/队列和可注销测试主体；幂等、通知去重、胶囊边界、撤回/屏蔽/注销后不泄露正文 |
| 6/P2 | 原生交互、时间与限流（MP-02/03/08） | 实际分享对象和下载资源；验证小程序码、原图预览返回、保存/打开/转发、跨日显示及可执行的限流提示 |
| 7/P1 | 微信交付 | 前述关键链通过后，按发布授权构建/上传、确认体验版、提审并处理反馈；每一步分别记录实际状态 |

每批修改运行 `npm run check`，页面/样式/依赖/构建变化另跑 `npm run build:mp-weixin`。依赖升级须保持DCloud编译包一致并遵循其兼容组合。手机验收按当前版本集中执行，历史开发版记录只用于追溯。
