### 页面与状态拆分

- **资料设置。** 页面保留导航、权限和其他个人字段。头像昵称区域单独管理已保存值、待确认选择和正在发送的请求。选择微信资料使用微信原生控件。随机、自选和恢复默认只更新预览，确认后才写入；普通资料自动保存不会带出待确认候选。头像和昵称都改变时按现有版本约束顺序写入，部分成功、冲突和结果未知保留各自恢复动作。
- **身份认证。** 分开读取「当前可用照片」「替换候选」「人工申请」。用独立的逻辑管理选图、上传、扫描轮询和私有预览。扫描中离页后从服务端恢复。姓名、学号和临时预览离页清理。迟到回执须匹配会话、页面及候选资产。取消替换时按现有契约移除指定候选。仍在人工审核或已通过时按现有规则呈现申请。
- **悄悄话。** 页面负责编排和路由。卡片、身份选择、互动行、暖评区按用途拆分。以服务端动作权限、内容版本和结果回执驱动交互，抱抱和收藏的状态按会话及帖子隔离。保留游客直接浏览、主动登录后续接、品牌菜单分享和本人原稿读取权限。沿用现有幂等重试；收藏、暖评审核、编辑与分享分别管理状态。
- **通知与文案。** 按现有导航方式计算浮窗位置，显示状态图标、标题、可选短说明及关闭按钮。页面错误和命令恢复独立于浮窗计时。复查资料、认证、悄悄话及共用通知涉及的举报、登录和公开入口，保留资格、隐私和操作后果等必要说明。

### 验收矩阵

- **原型对照。** 用同一批样例在 320、375、430 px 及常用字号／放大字号检查标题标签、两行摘要、收藏同行、弹层和热区。验证浅色、深色、微信胶囊、底部安全区和键盘展开。详情遵循原型，真实标题作为页面主标题，顶部沿用项目可复用的微信导航。
- **本地闭环。** 用甲乙账号验证公开帖 → 抱抱／收藏 → 暖评送审 → 管理端审核 → 公开回显，以及认证照片上传 → 扫描 → 离页恢复 → 替换／重试 → 人工审核。校验跨号隔离、旧帖无标题、弱网、并发替换、超时结果未知、迟到响应和分享失效。仅使用合成账号和材料，已有数据库数据用于兼容性走查。
- **真机。** iOS、Android 微信分别验证头像原生选择、昵称键盘建议、图片选择和私有预览、好友单帖分享 A/B 及返回。微信开发者工具用于先核对编译结果与交互。真实供应商扫描和存储需要配套服务条件，单独记录实测结果。
- **质量检查。** 每批运行 `npm run check` 和 `npm run build:mp-weixin`，保留既有构建产物分享检查。针对有回归风险的交互补测试。最终复查文档链接、固定指纹及工作区差异。
