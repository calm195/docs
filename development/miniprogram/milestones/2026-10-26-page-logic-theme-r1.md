## 测试发现与修复

| 范围 | 已复现问题与可测试验收 |
| --- | --- |
| 登录页 | 重复点击在首次登录未完成时提前导航；离页再返回后旧请求继续导航。页面提交锁和生命周期代次确保仅当前有效登录成功后跳转。 |
| 用户 Store | 并发资格刷新时旧成功响应覆盖新权限，或在最新刷新失败后重新开放资格。只接收最新请求、当前会话的资料与审核结果。 |
| 心愿页 | 账号变化未立即清空本人列表和编辑正文。同步监听身份，清空列表、表单和写入状态；列表同时核对会话及所有者。 |
| 会话与设置页 | 同账号换令牌后，计算属性仍缓存旧资料。会话代次改为响应式，缓存投影及时失效；令牌仍只在内存。 |
| 认证页 | 身份变化后姓名、学号和学生卡资产残留。同步清空私有资料并让旧请求失效。 |
| 页面交互隔离 | 新增守卫最初使用应用根判断页面，H5共用根时不适用。改为沿父链寻找页面实例，核对栈顶、可见状态，隐藏或卸载后阻止旧页动作，返回后恢复。 |

【取舍】全页面点击和选择事件通过公共守卫执行；公共容器随页面显示状态隐藏。这是防御性隔离，不能据此断言已找到用户此前点击穿透的根因。原生导航组件通过隐藏页面容器隔离。认证与心愿 picker 的复杂模板表达式改为具名方法，并对无效选项索引做边界检查。

主题实现详见原记录：17个页面复用 AppPage 与 Tailwind 语义样式，首页和设置页提供持久化亮暗切换。无依赖升级、无新增环境变量。
