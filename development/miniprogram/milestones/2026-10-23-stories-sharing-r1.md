## 实现与可测试验收标准

| 范围 | 本轮行为 |
| --- | --- |
| 本人故事入口 | 从我的心愿详情的已实现/已还愿状态进入故事管理，只传wishId；重新读取资格与目标心愿，绑定本人投影、精确id、有效版本、当前allowed_actions。隐私屏障、其他用户投影或失效资格无正文和写入口。 |
| 首次提交 | 非空白正文原样发送，不擅设500字限制；POST stories使用wish_expected_version=WishResult.version。202只说明待审及fulfilled，不认为已经公开；随后重新读取心愿审核状态。 |
| 编辑与撤回 | PUT story及POST story/withdraw使用expected_version=WishResult.version，不用故事content_version、Me.version或旧列表版本。编辑替换全文并重审，旧版停止公开；撤回故事不回退fulfilled。确认弹窗后再次复核对象与会话。 |
| 本人审核状态 | 展示story_review_result的待审/通过/驳回及原因建议；通过不等于当前仍公开，提供独立公开故事入口。协议没有非公开故事原文接口，不把心愿正文或本地快照当作故事，编辑要求填写完整新正文。 |
| 还愿墙与详情 | GET stories按不透明cursor分页，去重并拒绝重复游标；GET stories/id只取当前公开投影。正文、学校提示及作者公开标签由服务端给出，不补出应愿人身份。首页及公开主页故事卡提供入口。 |
| 分享创建 | 心愿详情与故事页进入分享页，用户主动生成；POST share-links只发target_kind、id及幂等键，服务端复核当前公开资格。分享没有本人的allowed_actions投影，不借用心愿动作或编造Me权限；先刷新认证资格，普通会话限制最终由服务端判定。 |
| 微信分享卡 | onShareAppMessage同步返回本端固定路由与ref，使用固定通用标题和本地通用PNG封面，不携带正文、昵称、标签或正文截图，不执行任意服务端路由。未准备、页面离开或会话变化时回退首页通用卡。 |
| 分享回流 | 有ref时忽略额外kind/id，每次onShow与手动刷新均GET share-links/ref重验，不从旧正文或缓存恢复。撤回、过期、注销、屏障或其他不可读结果清空旧内容；详情跳转再次读取。无ref的创建入口不会在onShow自动写入。 |
| 失败与隔离 | 离开清空正文、草稿和权限快照；换账号及代次隔离丢弃迟到响应。403/404或读取失败清空投影。写入防重复，409只重读不自动重发；网络结果不明也重新读取并提示手动核对。 |

## 取舍、限制与后续

事实：修改三个新页面、PublicContent组件、故事/分享API与类型、动作与校验工具、路由及首页/心愿详情/公开主页入口、通用封面、根README和回归测试。无新增依赖或环境变量。验证清单列出16个变更文件指纹。

实现取舍：本人故事借助所属心愿状态与动作管理；协议无非公开原文读取，不伪造草稿恢复。新版本填完整正文，刷新及离开都会清空输入。写入未确认时不自动恢复原幂等尝试，先重读，再由用户核对选择后续操作，服务端版本与状态继续约束写入。分享页保留无正文ref以便重入重验，正文仅在可见页内存；通用封面是本地几何图形，不含业务数据。不实现朋友圈、海报、业务图片、快照或追踪统计。

未完成的真实验证：微信登录后提交故事→扫描/人工审核→还愿墙公开→新版旧版下线→撤回及分享失效，真实好友卡片发出/接收、真机行为与生产HTTPS。后端独立测试不替代本端联合验收，当前空还愿墙不证明真实有内容时的渲染。公开主页后端缺口仍为前轮依赖。
