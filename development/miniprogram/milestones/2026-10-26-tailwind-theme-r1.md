## 实现、取舍与可测试验收

【事实】工程原已安装Tailwind CSS 4.3.3与weapp-tailwindcss，并配置Vite入口，故复用现有组合，不重复增加构建插件、不升级依赖。入口保持纯CSS；参考[适配插件官方接入说明](https://tw.icebreaker.top/docs/quick-start/v4/tutorial)。

| 范围 | 可测试验收标准与实现 |
| --- | --- |
| 样式复用 | 全部17个页面使用AppPage；移除重复局部样式，公共卡片、标题、按钮、输入框、picker、提示和错误通过Tailwind @apply生成，个别布局用工具类组合。 |
| 语义颜色 | Tailwind @theme inline将背景、表面、正文、次要文字、边框、强调、警告和错误映射到主题变量；容器内组件继承变量。 |
| 选择入口 | 首页和个人设置都有亮色/暗色按钮，显示选中状态；未登录及Mock环境可使用，无后端依赖。 |
| 持久化与降级 | Pinia共享主题，默认亮色；合法选择保存在既有storage封装中，坏缓存回退亮色；存储失败仍即时切换并提示无法保存。 |
| 跨页与原生区域 | 全局onShow混入同步导航栏文字/背景、页面背景与下拉文字；每个AppPage按共享状态响应更新，无DOM操作。 |
| 信息可读性 | 暗色覆盖表单与提示语义色；占位符使用主题色；原正文换行与长文本折行保留。 |

【取舍】采用手动亮暗两种模式，默认亮色；不提供跟随系统，也不修改系统外观。主题是设备偏好，不同账号共用本机选择。SCSS仅保留基础排版与盒模型，主题由CSS变量与Pinia驱动。
