## 接口核对

以下路径统一相对 `VITE_API_BASE_URL`，该地址须包含 `/api/v1`。14 项现有调用的方法、路径、字段与正式契约一致；本轮补充分页 limit 透传及调用编排修复。

| 功能              | 方法与路径                       | 关键输入/响应                                                                               |
| ----------------- | -------------------------------- | ------------------------------------------------------------------------------------------- |
| 微信登录          | POST /auth/wechat-sessions       | wx.login 的 code、client_request_id；无 Bearer/幂等键；返回 token/me                        |
| 本人资格          | GET /me                          | Bearer；刷新 verification、version、allowed_actions                                         |
| 当前会话退出      | DELETE /auth/session             | Bearer、Idempotency-Key；204 后清本地会话                                                   |
| 学生卡上传        | POST /me/student-card-assets     | Bearer、幂等键、单一 file multipart；202 仅表示受理                                         |
| 学生卡扫描状态    | GET /me/student-card-assets/{id} | 编码资产 ID；pending/approved/rejected                                                      |
| 当前人工认证记录  | GET /me/verification-request     | 无记录 404；返回申请版本、状态及驳回原因/建议                                               |
| 首次申请/驳回重提 | POST /me/verification-requests   | 原样姓名/学号、扫描通过资产、幂等键；首次省略版本，重提取 Verification.version；202 pending |
| 公开广场          | GET /wishes                      | category/campus/cursor/limit；只展示公开投影                                                |
| 我的心愿          | GET /me/wishes                   | state/cursor/limit；不发送公共分类/校区筛选参数                                             |
| 创建草稿          | POST /wishes                     | 心愿正文、分类、校区、可选身份标签、报答与期限；幂等键；201                                 |
| 编辑内容          | PUT /wishes/{id}/content         | 心愿字段、refresh_expiry、expected_version、幂等键；200                                     |
| 删除草稿          | DELETE /wishes/{id}/draft        | expected_version、幂等键；204                                                               |
| 提交审核          | POST /wishes/{id}/submit-review  | expected_version、content_version、幂等键；202，不视为已公开                                |
| 上架              | POST /wishes/{id}/publish        | expected_version、幂等键；按重读的 published/ready/expired 展示结果                         |

## 本轮修复

- 不透明游标允许点号、连续点号和 encodeURIComponent 保留的查询字符；路径穿越仍按路径段检查并拒绝。此前完整 URL 的字符限制会在请求发出前拦截合法签名游标，导致后续分页失败。
- 列表 API 透传契约 limit，公开列表与本人列表分别保留适用的筛选参数。
- 微信 code 交换为无 Bearer 请求，其 401 表示临时凭据不可用，不撤销当前已有本系统会话；受保护接口 401 继续清会话。
- 认证页只刷新本人资格，再独立读取一次审核记录；正常首次 404 不再触发全局错误 toast，页面仍区分未知/无记录/有记录，其他读取失败显示失败状态。
- 服务端 WishInput 的报答方式与期限可省略；本人内容响应类型允许省略，编辑时补全契约默认 sincere_thanks/7，避免合法草稿因缺少可选字段而无法保存。
- 首页及心愿页面同步真实写入已开放的状态，保留资格、动作、会话代次及版本检查。

前序同批修复还包含姓名/学号原样传输与 UTF-8 字节限制、原图选取、HTTP 状态与业务 code 分离；详情见阶段二记录。

## 服务探测与验证
