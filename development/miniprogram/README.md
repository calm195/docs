## 架构与请求边界

uni-app、Vue 3、TypeScript、Pinia；页面使用微信生命周期和原生组件，API 经统一 request 层，身份与令牌由 session 管理。会话凭据按API地址隔离持久化，权限启动时向服务端复核；请求和页面状态按会话代次、可见性及操作代次失效。

本轮统一在平台回调交付响应后处理会话、协议与错误，避免异步校验器抛错造成请求无法正常结束。换号后的迟到成功、401、普通错误及上传/网络失败全部拒绝，并抑制旧请求的全局通知；当前请求自己的401仍清理会话和反馈过期。
