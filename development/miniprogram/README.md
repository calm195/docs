# 小程序现状

## 体验版交互更新

`develop` 本轮源码版本为 `96c53825dc5db359aaa520a66a9c391cff03a6a0`。微信开发者工具已上传 `1.0.8-trial.20261107`，体验版设置及手机回归待确认。

### 本人悄悄话查看与时光胶囊入口

时光胶囊详情兼容服务端附带的 `preview` 字段。未解锁时摘要须为空，解锁后的非空摘要须与正文前三个码点一致。去除该字段后仍按详情契约校验，未解锁正文及其他额外字段继续拒绝。本轮 247 项测试及微信构建通过，体验版真机待复测。

2026-11-07，在下文所列 `develop` 工作区基点上，本人帖子从公开列表或「我的心事」先进入只读详情。已公开帖子显示暖评，草稿等未公开帖子显示本人可读内容和状态。点击「编辑」才加载编辑表单，取消后丢弃未保存的输入并重新读取详情。撤回「悄悄话」内的时光胶囊子标签，时光胶囊从「我的」独立进入。全量检查通过 246 项测试，微信构建通过。手机交互仍待验收。

### 头像和治理入口

2026-11-07，资料页使用微信原生选图，接受 2 MiB 以内的 JPG 或 PNG。用户确认上传后才切换已保存头像，个人中心同步显示回执。失败时保留原头像，结果未知时可用原请求重试。接口见[头像上传增量](../../contracts/avatar.v0.2.1-r2.md)。

举报和屏蔽入口统一为下划线文字链接，帖子与暖评的两项操作同排。微信开发者工具已使用项目测试图走通选图、预览、真实 CI 审核、COS 上传、资料和个人中心回显、恢复默认。悄悄话帖子和暖评入口样式已核对，联调时创建的屏蔽已解除。小程序 242 项测试及微信构建通过。手机仍需核对相册权限及 COS 合法域名。

黑名单从「我的」独立进入，个人资料与隐私页仅处理本人资料及隐私设置，不再读取黑名单。公开主页、心愿和故事的屏蔽文字链接进入独立黑名单页确认目标。列表分页、解除屏蔽和原请求重试沿用既有接口。小程序全量检查 244 项测试与微信构建通过。开发者工具中可见两个独立菜单项，经路由分别打开后，确认黑名单页显示真实会话的空列表，资料页保留头像设置。菜单点击跳转仍待设备复核。

### 页面跳转与还愿墙

还愿墙列表和故事详情复用同一套展示。列表卡片提供四行正文预览，详情显示完整正文并提供分享，公开作者、举报与屏蔽、合规提示照常展示。阅读故事与举报、屏蔽同排，查看心愿与校区、报答同排，还愿墙列表和故事详情均移除顶部介绍卡。移除了还愿墙的故事管理捷径，以及聊天、应愿、申诉、资料广场和暖评编辑里的跨模块捷径。微信开发者工具使用本地公开故事验证列表卡片、完整详情和进入站内分享页。全量 244 项测试和微信构建通过。

### 微信开发者工具联调

2026-11-07，已打开开发产物 `dist/dev/mp-weixin`，监听编译保持运行，模拟器连接本地API `http://127.0.0.1:18080`。真实微信code换会话与本人资料读取均返回200，当前微信账号未认证，发帖入口正确提示需要学生认证。

模拟器实际验证个人中心新菜单、亮暗主题、后台说明读取与本人确认、昵称提交202后经worker审核并下拉刷新回显、悄悄话标题和详情、列表抱抱与取消、暖评提交审核到公开，以及我的评论回跳原帖。编辑器经 `wx.startPullDownRefresh()` 触发原生下拉生命周期后保留20字未提交暖评。清理启动前的连接拒绝日志后，本轮操作未出现新的运行错误，存在微信基础库getSystemInfoSync弃用和开发工具热重载警告。

本轮发布、聊天和胶囊完整双账号链由同一开发API的HTTP测试完成，真实微信账号的认证状态未变更。手机触摸下拉、iOS/Android键盘和布局、弱网、真实分享与双设备链仍待验收。


2026-11-07，`develop` 工作区基于完整提交 `2a1cb6a1e84376e1727de2147b6cec3391f4f529` 开发，以下新增改动尚未提交。

## 模块实现

| 模块 | 当前能力 | 边界 |
| --- | --- | --- |
| 主导航与视觉 | 首页、心愿池、悄悄话、资料、我的五个入口；统一页面容器、浅/深色主题 | 自定义主导航重建根页面；原型中的独立搭子、鲤币、语音等没有扩展为已实现功能 |
| 登录与身份 | 微信code换会话、本人状态、学生认证上传及审核结果、资料隐私设置 | 后端AppSecret不进入客户端；合成卡片/身份不能冒充学校真实认证 |
| 心愿与匹配 | 公开列表、详情、创建/提交/上架、本人管理、应愿与唯一匹配、公开主页 | 公共投影已独立解析；操作以服务端动作与当前资格为准 |
| 聊天与故事 | 会话/通知、双向聊天、静默轮询、我/对方气泡、还愿编辑/墙、分享回流 | 已修复轮询丢失输入与方向显示；实际联系人分享投递仍需验收 |
| 悄悄鲤 | 三档身份发帖、编辑/撤回、已审昵称、暖评、抱抱、评论开关、通知、举报与解忧入口 | 标签需有效字典；关闭评论保留旧评论读取；公开失效时不回显旧正文 |
| 本人胶囊 | 新建、封存、列表、到期详情、取消/删除 | 到期前无正文；列表不暴露正文；不能跨账号读取 |
| 资料广场 | 认证查询/搜索/详情/复制、四类反馈替换、固定二维码投稿组件 | 已有本地真实联调；正式投稿二维码仍未配置，外部网盘下载未验收 |
| 安全与隐私 | 屏蔽/opaque列表/解除、警告、申诉、关怀、账号注销和匿名回执 | 危机与删除结果按服务端真实状态展示；外部依赖缺失不伪报完成 |
