# T002 错误码 v0.1.0

所有错误有非零code、message、稳定error_code与request_id；不含底层异常、凭据、身份或正文。

| HTTP | error_code |
| --- | --- |
| 400 | VALIDATION_FAILED |
| 401 | UNAUTHENTICATED |
| 403 | VERIFICATION_REQUIRED, FORBIDDEN |
| 404 | NOT_FOUND |
| 409 | VERSION_CONFLICT, STATE_CONFLICT, ACTIVE_WISH_LIMIT, DUPLICATE_APPLICATION, BLOCKED_INTERACTION, REVIEW_PENDING, ASSET_NOT_READY, IDEMPOTENCY_CONFLICT, WARNING_WAIT_REQUIRED |
| 429 | RATE_LIMITED |
| 500 | INTERNAL_ERROR |
| 503 | DEPENDENCY_UNAVAILABLE |

IDEMPOTENCY_CONFLICT是同键异摘要的技术命名补全；WARNING_WAIT_REQUIRED返回remaining_seconds，提前失败不阻止之后同键重试。INTERNAL_ERROR为异常恢复兜底，不是业务错误。503不允许安全能力失败时直通；404用于不可读对象避免枚举。ready为成功处理业务结果，不用ACTIVE_WISH_LIMIT；后者用于B01满额回退。
