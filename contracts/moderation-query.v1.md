# 内容治理查询增量 v1

继承全站契约的后台会话、岗位授权和案件详情权限。本版仅扩展 `GET /api/v1/admin/moderation-tasks` 列表查询。

| 参数 | 含义 |
| --- | --- |
| `q` | 案件编号、内容登记编号或实体内容编号的片段匹配（去除首尾空白，最多 80 字）；不搜索正文或上下文会话 |
| `status` | 默认 `human_required`；可选 `approved`、`rejected`、`all` |
| `kind` | `wish`、`application`、`message`、`story`；省略表示全部类型 |
| `cursor`、`limit` | 沿用游标分页，筛选变化后从首页查询 |

筛选由服务端在分页之前执行。`all` 模式先列出 `human_required`，再列其他状态，同组使用稳定编号排序。游标绑定筛选及排序分组，不能跨筛选复用。

搜索仍限于当前岗位可访问的普通审核案件，不扩大危机隔离或私聊上下文权限；列表不批量解密正文。管理端初次进入及重置筛选均显示待人工审核案件。
