## 审查重点与修复

| 问题 | 影响与修复方式 | 回归依据 |
| --- | --- | --- |
| 刷新期限重建正文版本未复制图片关联 | 图文版本失配；新版本沿用有序图片绑定并验证资源状态 | 原生心愿生命周期/图片回归 |
| 无 wish_id 的作者图片预览绕过当前来源限制 | 缓存URL可读取已换下/删除或受屏障内容的图片，同图跨心愿复用也可绕过来源限制；统一复核有效当前引用和全部来源隐私/治理 | 图片归属、换图、删除及限制读取回归 |
| 公开主页/分享心愿统计与主详情不一致 | 默认零值及本人收藏/归属状态不正确；统一当前读者批量投影 | 同目标跨入口统计一致性 |
| 新评论待审取消图未完整覆盖屏蔽与处罚关系 | 解除屏蔽后旧审核可能重新公开；补全作者/根楼/回复目标取消条件 | 原生审核与互动关系回归 |
| 本人回复原稿未继承被引用评论屏障 | 根楼或目标被隔离仍可读取关联原稿；引用屏障参与本人投影 | 原稿隐私/治理读取回归 |
| 选图返回未复核会话与页面归属 | 换号/离页后继续上传；在选图返回及逐图上传前校验代次 | 小程序生命周期行为测试 |
| 收藏页已加载数据换号未即时清除 | 旧账号列表可能继续显示；会话变化立即清空并废弃旧响应 | 已加载状态与换号回归 |
| 未读刷新在已有请求中丢失 | 已读/换号刷新被旧总数覆盖；记录待刷新并隔离旧响应 | 请求并发与重刷回归 |
| 评论列表缺少独立读代次 | 慢旧请求覆盖提交后的新列表；按读取代次丢弃旧结果 | 评论列表乱序响应回归 |
| 心愿保存失败清稿及丢原幂等键 | 新附图草稿与结果未知请求无法核实；保留原内容/版本/键重试 | 保存失败及未知命令回归 |
| 管理端旧词条空分类被新解析器拒绝 | 默认规则详情打不开；兼容合法空分类 | 解析单元与真实Chrome详情读取 |
| 管理端图片读取未进入统一撤权处理 | 401/403后已加载预览残留；清理Blob并触发会话/权限处理 | 第二张图片撤权清第一张预览与退出回归 |
| 图片序号接受第四个位置 | 与最多三图契约不一致；序号限定0–2 | 不合法图片投影解析回归 |

| 评论通知使用不完整的手写可见条件 | 作者受罚或根楼失效时通知定位不一致；复用心愿领域公开资格 | 通知定位与处罚/屏障回归 |
| 旧客户端GET浏览写入与注销缺少共同锁 | 清理后可再次写入计数；同事务锁定父账号/心愿并复核 | 浏览与删除并发回归 |
