| --- | --- |
| 应愿中或已实现，处罚/拉黑，各合法方退出，许愿人受罚或未受罚，满额/未满额，原期限过/未过 | 目标一律已撤下、不公开、不占额度、期限不变，原人解绑/申请失效/会话只读；许愿人限制保留。已还愿主动解绑拒绝。 |
| 普通已实现回退应愿中，保留原匹配 | 仍适用B01，满3条拒绝，不能拿例外退出绕过保留匹配回退的额度要求。 |
| 例外退出后重新上架 | 本人重审，选刷新则从新上架起算，不刷新已过期则不可公开；满额待上架；处罚/违规/危机限制未解除仍不可公开。 |
| 私聊待审后实现/还愿/解绑/拉黑/处罚，再人工通过 | 已取消、不送达、不自动重放；未变化且允许可写才送达。恢复旧状态也不复活取消任务。 |
| 留言待审，后撤销/过期/修改/匹配给他人/拉黑/注销，再审核 | 不生效、不展示为可同意、不新建匹配；待审留言原本不向许愿人展示。 |

| 注销与旧审核/通知重试交叉 | 普通数据删除、任务取消，迟到任务不得生成正文、通知、普通身份关系或匹配；证据留在案件授权范围。 |
| 许愿人分别在应愿中/已实现/已还愿注销 | 删除其普通心愿/故事与关联，存活应愿人无正文/普通消息且不能继续动作，不留活跃孤立记录。 |
| 应愿人分别在应愿中/已实现注销 | 许愿人自有心愿转已撤下，可后续重审，当前不占额度；当前匹配不能继续完成/还愿。 |
| 应愿人在已还愿注销 | 保持已还愿，不占额度，不可回退/重招；保留许愿人自己的故事，清除注销者身份引用，受影响公开内容重审，普通会话删除。 |
