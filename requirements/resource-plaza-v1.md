## 1. 来源与基线关系

【用户明确要求】本次会话原文：

> 新首期需求，资料广场：现有各种资料，已有下载链接如百度云盘；小程序展示各资料信息，可复制下载链接，非认证用户不可查看，可分类搜素、模糊搜搜；管理端录入资料信息并上架。

其中“分类搜素、模糊搜搜”按分类搜索与关键词模糊搜索整理。资料及外部下载链接已存在是用户提供的输入事实；本次未取得实际资料清单，也未核验任何外部链接。

本增量在[需求基线 v0.2](baseline.md)之上增加资料广场，不重编号既有需求。原基线 SHA-256：`fed56e2811cd21c5c5d461a35d9ace525b6f9bc142a01a6a1f2048303da54810`。原始输入、旧基线及审批保持固定；[悄悄鲤增量](whispers-v1.md)、[用户管理 v1.1](admin-users-v1.1.md)及[直接处置 v1.2](admin-users-v1.2.md)继续按各自适用范围生效。

## 2. REQ-023 资料展示、检索与上架

优先级建议 P1，属于首期范围。以下为明确要求及其可测试验收标准；第3节的字段、检索和运营细化尚属建议。

| 编号 | 要求与边界 | 可测试验收标准 |
| --- | --- | --- |
| 023-A | 只有当前符合认证与账号权限要求的用户可查看资料信息和下载链接；小程序入口和服务端读取均受控 | 认证通过的有效账号可读取；游客、未认证、认证待审、认证驳回者访问列表、分类搜索、关键词搜索、详情及链接读取均被拒绝。直接请求接口、携带已知资料 ID 或旧分页参数不能绕过限制；拒绝响应不含资料标题、简介、链接或提取码 |
| 023-B | 小程序展示管理端已上架资料的信息 | 上架资料可在列表及详情中查看；未上架资料不出现在列表或搜索结果，直接访问其详情也不能读取；同一资料在列表与详情中的信息一致 |
| 023-C | 支持分类搜索 | 选择某分类后只返回归属该分类且已上架的资料；无匹配结果显示空状态，不混入其他分类资料；切换分类后不混入上一次结果 |
| 023-D | 支持关键词模糊搜索 | 输入资料名称的一部分能够找到相应已上架资料，无须完整输入标题；无匹配结果显示空状态；修改关键词后旧请求的晚到响应不能覆盖新结果。具体匹配字段及规则见第3节建议 |
| 023-E | 可复制已有外部下载链接，如百度云盘链接 | 点击复制后，剪贴板内容与当前获准访问资料的下载链接一致；只有系统复制成功才提示成功，失败可重试；不能将空值、其他资料链接或错误提示当作下载链接复制。是否附提取码见第3节建议 |
| 023-F | 管理端可录入资料信息与已有下载链接 | 有资料管理权限的后台人员可录入并保存，重新打开后字段与保存结果一致；输入无效时明确提示并保留可修正的输入；小程序普通用户不能通过管理接口录入资料 |
| 023-G | 管理端可将资料上架供符合条件的小程序用户查看 | 录入但未上架的资料对小程序不可见；执行上架成功后可被查询；缺少有效下载链接时不能上架；重复提交上架不生成重复资料。其他必填字段随确认后的字段规则校验 |
| 023-H | 管理权限与读权限由服务端按当前主体检查 | 无后台权限账号不能录入、上架；有小程序认证不等于有后台权限；后台角色撤销后旧页面不能继续写入。具体后台角色分配见第3节建议 |

【既有约束的适用】“认证”复用 REQ-002 的学生认证，不新增另一套资料认证；已认证者毕业不自动失效。封禁账号按既有游客权限处理，因此不得查看资料；禁言本身只限制写入，认证仍有效者可浏览及复制链接。注销中、已注销、会话失效或不再满足认证要求时拒绝新读取，前端在获知状态变化后清除资料展示。账号解封、禁言解除不绕过认证要求；本增量不改 REQ-016、REQ-018 及直接处置 v1.2 的规则。

## 3. 建议细化（尚未作为用户逐项确认的要求）

以下为最小可实施建议，后续需求细化及正式契约应明确采纳范围；不能仅因本文固定就视为建议已获批准。

### 3.1 资料信息

| 字段 | 建议规则 | 用途 |
| --- | --- | --- |
| 资料标题 | 必填纯文本 | 列表、详情展示及关键词检索 |
| 所属分类 | 必选单个有效分类，首期采用单级分类 | 分类筛选；具体分类名称待资料方提供 |
| 简介 | 可选纯文本 | 简要说明资料内容；详情展示并参与关键词检索 |
| 下载链接 | 必填，每份资料先支持一个 HTTP/HTTPS 外部链接 | 百度云盘仅为示例，不据此限制为单一服务商；保留实际分享链接的必要参数 |
| 提取码 | 可选；外部资料有提取码时一并录入 | 详情展示，可与链接组合复制；无提取码时只复制链接 |
| 上架状态、创建及更新时间 | 系统维护，不要求运营手工填写 | 状态区分、排序及信息维护 |

建议列表显示标题、分类和简介摘要，详情显示完整简介、下载链接及提取码。字段长度上限、页面入口、排序与分页大小在后续设计中明确；列表需要分页并区分加载、空结果、失败、需认证状态。

### 3.2 分类与模糊搜索

建议分类与关键词可同时使用，取条件交集；“全部分类”不施加分类限制。关键词采用标题或简介包含关键词的匹配，先按权限和上架状态过滤，再执行搜索和分页。空白关键词等同未设置关键词；查询条件变化时从第一页重新查询。

建议中文按字面子串匹配，拉丁字母忽略大小写；`%`、`_` 等特殊字符作为普通字符，不当作通配语法。例：标题“高等数学期末复习资料”可被“数学”或“期末”匹配；选中“英语”分类并搜索“数学”时，只能返回英语分类下本身匹配的资料。首期建议不增加拼音、纠错、语义搜索或外部文件正文检索。

### 3.3 管理与维护

建议由审核运营和超级管理员管理资料；危机处置角色不因既有案件权限自动获得资料录入、上架权限。具体授权需在需求细化时确认，并在正式契约中逐项写明。

建议采用“未上架草稿 → 已上架 → 已下架”的最小状态流程，补充编辑与下架能力以便纠正资料信息、替换失效链接。上架后编辑先下架、保存后由运营重新上架；不增加独立双人审核、定时上架、批量导入或复杂分类树。编辑、下架和分类维护的范围均为建议，不冒充本次用户明确要求。

若采纳下架能力，其验收应覆盖：下架后新的列表、搜索、详情及复制取链请求均不可获取该资料；旧详情页操作时重新校验当前状态并清除失效内容。管理操作记录操作者、时间、目标及动作；日志不复制外部链接、提取码或学生身份资料。

## 4. 范围与可验证边界

【本次明确范围】平台展示资料信息并复制已有外部链接；尚未提出平台上传或托管资料、代理下载、网盘账号接入、自动抓取网盘内容、在线预览、收费、学生投稿或收藏评论需求，不将这些能力列入本次交付承诺。资料文件本身不等于小程序图片/视频发布能力，既有媒体范围不因此改变。

【访问控制边界】认证限制适用于平台内资料信息与链接的获取。已经复制到平台外的链接无法仅靠平台后续封禁、注销或资料下架撤回；外部文件的访问权限、有效期及实际下载结果由资料来源决定，不宣称平台能保证外部网盘仅认证学生可访问。需要撤回外部访问时须由资料提供方在来源处处理。

【验收边界】小程序复制成功只证明链接已复制，不证明外部文件可下载。真实验收需使用资料方提供的样本，分别核对平台展示/复制结果和外部链接可用性；不以模拟链接或静态页面结果宣称完成真实联调。REQ-021 的普通列表性能要求继续适用，资料量、搜索场景与负载需纳入后续验收方案，本次没有性能测量。
