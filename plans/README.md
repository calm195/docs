# 跨端后续安排

## 展示字典与操作通知交付顺序

先显式应用展示字典追加迁移，再更新提供字典读取与维护接口的后端，随后交付管理端和小程序。协议见[展示字典增量](../contracts/display-dictionaries.v0.2.1-r1.md)。使用同一组数据验证管理端改名、版本冲突、原请求重试及两端读取，确认未知和停用条目的展示不会改变权限或状态规则。

两端操作通知复用各自现有组件，按成功、警告、错误和结果未知设置时长；关闭或超时只清理展示，不清除业务错误、待确认请求和回执。逐页核对主动操作与后台轮询，补充窄屏、键盘和微信真机验收。目录调整保持路由与分享地址兼容，清理需核对动态入口和生成契约用途。

## 资料文件与登录改进交付顺序

先显式应用0015资料文件迁移，再更新API与隐私清理worker，然后交付管理端与小程序。契约见[体验版改进](../contracts/trial-improvements.v0.2.1-r2.md)。本地已按此顺序完成联调；目标环境仍按实际发布授权执行。微信下载域名、手机明暗导航和会话重启单独验收。

| --- | --- | --- |

| 4. 真机与体验 | 小程序双设备/弱网/双主题；管理端窄屏/键盘/错误恢复；后端配合异常注入 | 当前SHA下关键页面链及恢复路径通过；二维码、真实分享和下载单独验证 |
