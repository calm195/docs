## 本轮开发条件与协作

用户已允许启用子代理、启动本地服务、使用本地数据库且无需备份。执行可分为管理端、小程序、后端三个工作范围；主代理维护共享契约、文档、整体验收和集成。各端共享外壳、路由、状态库和样式由该端同一执行者统筹，避免同时覆盖；数据库迁移与共用测试数据由后端统一安排。

本机可启动 API、前端预览、微信开发构建和场景所需 worker；启动前核对已有进程、端口和数据库目标，复用适合的服务。按本机迁移账本显式升级、准备合成账号与业务数据，备份不作为本轮本地开发前置步骤。“无需备份”不意味着自动清库；现有主密钥、迁移账本和非本轮数据继续保留。数据库集成套件使用自身临时实例，避免并行用例改写共享联调数据。

服务命令与配置以各源码 README 和[后端开发者指南](../../liyuanci-backend-go/DEVELOPER_GUIDE.md)为准，旧记录中的端口和迁移状态在实施时重新核对。任务结束停止本轮启动且不再需要的进程，保留原有服务；专用合成联调数据可保留供复验，隔离集成套件的临时数据库自行清理。提交、推送、生产部署和微信上传按对应任务授权执行；本计划记录本地实施条件，不把这些条件扩展为生产操作授权。
