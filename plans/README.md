## 联合验收顺序

| 阶段 | 协作与关闭标准 |
| --- | --- |
| 正式输入 | 按[后端主清单](../development/backend/defects.md#需要用户提供或协调开通的清单)核对资源、资料和权限；依赖不足只阻塞相关场景 |
| 核心业务 | 同一配套版本和隔离账号，管理端按真实岗位、小程序按A/B微信走通认证、心愿/聊天/还愿、树洞/胶囊、资料、安全及包分配；含拒绝、旧版本与重复操作 |
| 权限与恢复 | 三端验证撤权/换号/迟到响应；后端验证并发、清理、两域恢复前重删与失败门禁，数据库回执不扩大为外部全副本删除证明 |
| 设备与交互 | iOS/Android、双主题、弱网、原生选图/预览/分享/下载；管理端窄屏、键盘与错误恢复 |
| 容量与交付 | 固定负载下分别验证图片、分页和配对/发布成本、积压恢复与告警；生产部署、微信上传/体验版/提审/正式发布按授权分别记录 |

各端后续事项：[后端](../development/backend/plan.md)、[管理端](../development/admin/plan.md)、[小程序](../development/miniprogram/plan.md)。启动和部署命令集中在[后端开发者指南](../../liyuanci-backend-go/DEVELOPER_GUIDE.md)，不在计划中复制易失效的命令。
